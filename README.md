# 🎓 Student Management System

A Student Management System developed using C language with
File Handling and CRUD operations.

## 🚀 Features

- 🔐 Admin Login
- ➕ Add Student
- 👀 View Student
- 🔍 Search Student
- ✏️ Update Student
- 🗑️ Delete Student
- 📊 Student Statistics
- 💾 File Handling
- 🔄 Auto Save

## 🛠️ Technologies Used

- C Language
- Structures
- Arrays
- Functions
- File Handling
- CRUD Operations

## ⚙️ How to Run

1. Open the project in VS Code.
2. Open `code.c`.
3. Compile and run the C program.
4. Open `index.html` in a browser to view the web interface.
